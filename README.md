Neon Coast Cover Studio — an offline web app that turns any photo and caption into GTA 6-style cover art: multi-panel layouts, sunset/neon grades, bold poster lettering, exported as a PNG in 1080×1080, 1080×1350 or 1920×1080. Your photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
