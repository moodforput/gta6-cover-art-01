Neon Coast Cover Studio is an offline web app that turns your photos and a caption into GTA 6-style poster art.

Pick a layout — four-panel, hero-and-three, full-bleed, nine-panel or tilted snapshots — grade it with a Vice City sunset or neon look, and set the title in bold poster lettering. Your photos stay on your own machine; nothing is uploaded. Export the finished cover as a PNG in 1080×1080, 1080×1350 or 1920×1080 to share.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
